Search Features
Basic Search
lighting rentalMatches records containing either word. Best matches rank first.
"exact phrase"Double quotes require the whole phrase to appear.
-wordExcludes records containing that word.
-"phrase here"Excludes records containing that phrase.
ExactThe toggle in the search bar restricts results to literal substring matches. Turns on automatically for request numbers and project codes.
Field Filters — type /

Type / in the search bar to pick a field, then enter a value. Filters become chips and can be combined with each other and with normal search text.

project_code:'2026TEG'Single quotes — matches if the field contains the text.
project_code:"2026TEG-P0290"Double quotes — the field must match exactly.
Custom valuesSuggestions only appear once you start typing — any text works, not just a suggested value.
Click a chipTurns it off without deleting it (goes grey). Click again to turn it back on.
Double-click a chipEdits its value.
Filter menuThe filter menu lists every field under “Add Field Filter” — click one to start that filter with the cursor already in the chip.
Type filtersYou can also type field:'value' tokens directly and press Enter to turn them into chips.
Available fields:
particular_itembusiness_unitproject_nameproject_codeproject_managersupplier_account_name

Shareable Links

Search terms, filters, sorting, and display settings are written into the address bar as you change them — copy the URL to share the exact view.

?q=Search terms, including field filters.
?exact=true or false.
?tab=all, particulars, suppliers, projects.
?sort=dateasc, datedesc, priceasc, pricedesc, projaz, projza.
?status=Comma separated: approved,under review,recalled,rejected.
?outsource=show or hide.
?currency=php or usd.
?group=none, business unit, project, supplier.
?theme=system, light, dark.
?exchangerate=PHP per 1 USD, e.g. 57.
?showprice=default, php, usd.
?qoff=Field filters that are present but switched off.
Live Data

The page opens on the bundled database, then always fetches the latest records from the Lark base in the background. A bar at the bottom shows progress.

Auto-apply (on)The default. New data is loaded automatically when the fetch finishes (brief "Loading latest database" overlay). Toggle it in Settings.
Auto-apply (off)The fetch still runs, but the bar offers Reload / Dismiss so you decide when to swap — a search in progress is never disturbed.
Force refreshSettings → Database. Fetches and applies the latest data immediately, regardless of the toggle.
A failed fetch or a short/partial read is always surfaced and never applied silently.
